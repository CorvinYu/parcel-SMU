## ✨ 功能

### 原项目能力（已同步上游 v1.0.68）

- 自动解析短信中的取件码与地址，展示到桌面卡片（支持暗色模式）
- 支持桌面小组件、老人模式
- 自定义解析规则（可取件码前缀关键词）
- 长按取件码添加备注、分享
- 按时间过滤；显示/隐藏格口号、时间
- 监听第三方 app 通知，自动保存取件信息
- 支持淘宝身份码 / 拼多多身份码
- 地址归类

### 海大版新增

- **快递中心条码**：把微信「进出快递中心」的专属码截图导进来，识别后随时出示
  - 两种常驻形态：**顶部常驻条** / **底部浮窗**（高度可拖动调节；取件码多到占满屏幕时**自动让位**缩小）
  - **完全离线**识别（ZXing），不依赖 Google Play 服务；也可一键切「原图保真」模式
- **取件路线**：按取件码里的货架号排出**一条最短取件顺序**
  - 场地模型**直接来自平面图 Excel 的填充色**（3 条纵向干线：西侧靠闸机那条 / 主通道 / 东侧；
    9 条横向走廊带；闸机带），**不手写通道假设**；取件点投影时**绕开墙与货架**
  - **快递站 / J 柜列区 / 顺丰 S 区 / 大件 Y 区**四类**全部纳入**规划
    （S 按格位横向、J 柜列按格位纵深并把柜列内走位计入距离）
  - **顺丰规则**：取了 S 件**必须先在「顺丰专用闸机」出库**；有普通件时出库后继续取、最后从
    「7个普通闸机」出库并出站直接走人；**只有顺丰件时出库机不能出站**，还要走到「顺丰和无快递出口」出站
  - 顺序是**精确最优解**（Held–Karp 子集 DP；已与暴力枚举逐例比对，含出库点的全部合法插入位置）
  - **首页列表可直接按路线排序**（菜单「按取件路线排序」，默认开）：卡片上标 ①②③，跟着序号取即可
  - 场地参数由 Excel 自动生成，无需手调；仅 **J 柜列每列格数**可在界面里填（该值尚未实测）
- **列表三分类**：快递站 / 快递柜 / 校外，支持**横向跟手翻页**
  - 快递柜卡片左侧用大号数字标出柜号，自助取件一眼可见
- **页面背景**：预设渐变或自定义图片（模糊、遮罩强度、缩放模式、作用范围可调）
- **条码试验**（隐藏的实测页）：把同一个取件码按 Code128 / Code39 / ITF / EAN-13 / 二维码
  五种码制渲染出来，供到快递柜柜机上**逐台实测**能否扫码取件
  - 结论先摆在这里：丰巢官方取件只有「一键开柜 / 输码取件 / 忘记取件码」三条，
    **没有柜机扫用户取件码这条路**；能不能扫开取决于那台柜机的固件，**测出来才知道**

## 🔎 取件码分类规则

| 类别 | 判据 | 样例 |
|---|---|---|
| **快递站**（人工货架） | 短信正文含「海事大学」且取件码**含字母** | `D8-6`、`J5-21`（J 柜列）、`S3-2-2628`（顺丰）、`Y5-7-1`（大件） |
| **快递柜**（自助取件） | 短信正文含「海事大学」且取件码为**纯数字** | `54018314`、`69824579` |
| **校外** | 短信正文**不含**「海事大学」 | — |

> 分类按短信**正文**判定，而不是解析后的地址——有些短信的解析地址里并不含「海事大学」。
>
> 取件码形如 `<排字母><货架号>-<格号>`（如 `D8-6`），顺丰/大件可能是三段式；
> 若短信里只给了货格号、没写「格口」，应用会把取件码本身当作货格号来用（路线功能依赖这一点）。

## 📖 使用说明

1. **桌面卡片**：在系统「全部卡片 / 插件 / 安卓小组件」里添加
2. **快递中心条码**：右上角菜单 →「海大版功能 → 快递中心条码」→ 导入专属码截图 → 按需开启常驻形态
3. **取件路线**：右上角菜单 →「海大版功能 → 取件路线」；或直接在首页用「按取件路线排序」看 ①②③ 序号
   （需要短信里带取件码/货格号，如 `D8-6`）
4. **条码试验**：右上角菜单 →「海大版功能 → 条码试验（柜机扫取件码）」，带去快递柜实测
5. **无法识别的短信**：某些无发送者号码的服务信息短信可能识别不了，可关闭此类短信或开启第三方通知监听作为补充
6. **小米手机权限**：`权限管理 → 其他权限 → 通知类短信 → 始终允许`
