## ✨ 功能

### 原项目能力（已同步上游 v1.0.68）

- 自动解析短信中的取件码与地址，展示到桌面卡片（支持暗色模式）
- 支持桌面小组件、老人模式
- 自定义解析规则（可取件码前缀关键词）
- 长按取件码添加备注、分享
- 按时间过滤；显示/隐藏格口号、时间
- 监听第三方 app 通知，自动保存取件信息
- 支持淘宝身份码 / 拼多多身份码
- 地址归类

### 海大版新增

- **快递中心条码**：把微信里的专属码截图导进来，识别后随时出示
  - 四种出示形态：顶部常驻条 / 底部浮窗 / **底部自动填充**（为取件码自动让位）/ 全屏出示（亮度自动拉满）
  - **完全离线**识别（ZXing），不依赖 Google Play 服务
- **取件路线**：按货格号（如 `D5-23`）自动排出一条最短取件顺序
  - 走行距离按场地真实拓扑计算，顺序是**精确最优解**（子集 DP，非贪心近似）
  - 场地参数（排字母序列、是否折返回入口）可在界面内修改
- **列表三分类**：快递站 / 快递柜 / 校外，支持**横向跟手翻页**
  - 快递柜卡片左侧用大号数字标出柜号，自助取件一眼可见
- **页面背景**：预设渐变或自定义图片（模糊、遮罩强度、缩放模式、作用范围可调）

## 🔎 取件码分类规则

| 类别 | 判据 | 样例 |
|---|---|---|
| **快递站**（人工货架） | 短信正文含「海事大学」且取件码**含字母** | `D8-6`、`S3-2-2628`（顺丰）、`Y5-7-1`（大物） |
| **快递柜**（自助取件） | 短信正文含「海事大学」且取件码为**纯数字** | `54018314`、`69824579` |
| **校外** | 短信正文**不含**「海事大学」 | — |

> 分类按短信**正文**判定，而不是解析后的地址——有些短信的解析地址里并不含「海事大学」。

## 📖 使用说明

1. **桌面卡片**：在系统「全部卡片 / 插件 / 安卓小组件」里添加
2. **快递中心条码**：右上角菜单 →（海大版功能）快递中心条码 → 导入专属码截图 → 按需开启常驻形态
3. **取件路线**：右上角菜单 → 取件路线（需要短信里带格口号，如 `D5-23`）
4. **无法识别的短信**：某些无发送者号码的服务信息短信可能识别不了，可关闭此类短信或开启第三方通知监听作为补充
5. **小米手机权限**：`权限管理 → 其他权限 → 通知类短信 → 始终允许`
