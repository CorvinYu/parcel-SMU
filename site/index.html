Haida Edition

海大版专属能力

在原项目（已同步上游 v1.0.68）基础上，为上海海事大学快递站做的四件事。

快递中心条码 · 常驻出示

把微信里的专属码截图导进来，识别后随时出示。完全离线（ZXing），不依赖 Google Play 服务。

  • 两种常驻形态：顶部常驻条 / 底部浮窗（高度可上下拖动调节；取件码多到占满屏幕时自动让位缩小）
  • 菜单里另有隐藏的「条码试验」页：把取件码按 Code128 / Code39 / ITF / EAN-13 / 二维码五种码制渲染，带去快递柜实测能否扫码取件
  • 识别三级递进：整图 → 深色横带裁剪 → 中心裁剪

取件路线 · 精确最优

把短信里识别到的取件码 / 货格号自动排成一条最短取件顺序；场地拓扑按 2026-09-29 现场踩点重建。

  • 顺序是精确最优解（树度量 + 子集 DP），不是贪心近似
  • 四类分区全部纳入：主货架区、J 柜列区、顺丰 S 区、大件 Y 区（含 y2/y4/y5/y7 反向编号与 y8-行-子位 三段式）
  • 场地按现场踩点建模：16 排（无 I/J）、每两排背靠背共用一条横向通道、主纵向通道在货架 4 与 5 之间，同一条通道南北两侧可直接横穿
  • 首页列表可按取件路线排序（菜单「海大版功能 → 按取件路线排序」，默认开），卡片上标 ①②③，跟着序号取即可
  • 场地参数（排字母、通道间距、入口到主通道距离、横穿代价、是否折返）界面内可改
  • 适用范围：带「格口」的写法（如「放入 7 号柜 23-32 格口」）与实体货格号（D8-6、S3-2-2628、J5-21）都能识别

列表三分类 · 横向跟手翻页

快递站 / 快递柜 / 校外 分开成三页，互相之间横向跟手滑动切换。

  • 快递柜卡片左侧用大号数字标出柜号，自助取件一眼可见
  • 分类按短信正文判定（有些短信解析出的地址里并不含「海事大学」）

Install

安装与升级

Android 10（API 29）及以上。装完不用登录，也不需要注册。

下载安装包

点页面上的「下载 APK」按钮，保存 parcel-spu-v0.1.8.apk（22.3 MB）。手机浏览器直接下载的话，下拉通知栏点安装即可。

允许安装未知来源应用

系统提示「禁止安装未知应用」时，选择允许来自此来源，然后继续安装。装完可以把这个权限关掉。

授予短信权限

首次打开会申请读取短信，用于自动解析取件码。小米手机还需要额外设置：权限管理 → 其他权限 → 通知类短信 → 始终允许，否则取件短信可能被拦截而收不到。

把取件码放上桌面

在系统「全部卡片 / 插件 / 安卓小组件」里找到「海大取件码」添加即可。之后也可以在右上角菜单里开启快递中心条码、取件路线等功能。

FAQ

常见问题

安装时提示「应用未安装」或签名冲突怎么办？

说明手机上还有用旧签名密钥打包的版本（v1.0.57-haida.1 及更早）。请先卸载旧版，再安装最新版。签名密钥换过之后，新旧两个包无法互相覆盖。

有些短信解析不出来？

分类与解析依赖短信正文特征，某些无发送者号码的「服务信息」短信可能识别不了。可以：①在菜单里开启监听第三方 App 通知作为补充；②用「新增自定义取件短信 / 新增规则」手动补一条规则。不确定格式的短信不要硬猜，直接加规则最稳。

小米手机收不到取件码？

需要给到「通知类短信」权限：权限管理 → 其他权限 → 通知类短信 → 始终允许。只给普通短信权限时，系统会拦掉这一类通知短信。

快递中心条码导入后识别失败？

识别策略是三级递进（整图 → 按深色横带裁剪 → 中心裁剪）。建议直接导微信里的原始截图，不要二次截图或强压缩，条码边缘越清晰成功率越高。

取件路线排不出来？

取件路线的输入是短信里识别到的取件码 / 货格号：带「格口」的写法（例如「放入 7 号柜 23-32 格口」）与实体货格号（D8-6 / S3-2-2628 / J5-21）都能识别（0.1.8 起补齐后者）。若还是排不出来，先确认菜单里的「按取件路线排序」是开着的，再到「取件路线」页看「无法定位」里列出的原文；场地参数（排字母、通道间距、入口到主通道距离、横穿代价、是否折返）都可以在界面里改。

收费吗？有广告吗？会上传我的数据吗？

免费、无广告。项目是开源分支：上游 shareven/parcel（MIT），海大版改动公开在 CorvinYu/parcel-SPU，代码可以自己查看甚至自行编译。条码识别完全在本地完成，不依赖 Google Play 服务。

有 iPhone / iOS 版吗？

没有。这是 Android 应用，依赖系统的短信读取与桌面小组件能力。
