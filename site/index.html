Haida Edition

海大版专属能力

在原项目（已同步上游 v1.0.68）基础上，为上海海事大学快递站做的四件事。

把微信里的专属码截图导进来，识别后随时出示。完全离线（ZXing），不依赖 Google Play 服务。

  • 两种常驻形态：顶部常驻条 / 底部浮窗（高度可拖动，列表占满时自动让位）
  • 识别三级递进：整图 → 深色横带裁剪 → 中心裁剪

把短信里识别到的取件码 / 货格号自动排成一条最短取件顺序，首页按 ①②③ 取即可。

  • ≤16 件是精确最优（Held–Karp），不是贪心近似
  • 有顺丰件会插一步「出库」，路线终点是出站闸机

列表按 快递站 / 快递柜 / 校外 三分类，横向跟手翻页。

  • 纯数字 ⇒ 快递柜，左侧大号数字就是柜号
  • 含字母 ⇒ 快递站（顺丰 S、大件 Y、J 柜列都在这里）

场地按实地分米级采样逐格建模：3362 个可走格、3 条纵向干线 + 9 条横向走廊、3 处闸机带。

  • 首页可挂地图窗格（浮在列表底部、高度可拖、可收起成胶囊）
  • 地图取件页：顶部当前取件码 + 整段序列，点一下标记已取并自动前进
Features

功能一览

沿袭原项目（已同步上游 v1.0.68）的日常能力，装完即可用。

桌面小组件

取件码直接摆在桌面上，不用每次翻短信。

短信自动解析

自动解析取件码与地址、按地址分组；不认识的短信可以自己加规则。

第三方通知监听

监听快递类 App 通知，补齐短信覆盖不到的部分。

地址归类

把同一驿站的不同写法归一，列表不再被拆成十几组。

老人模式

大字号大按钮，长辈也能自己看取件码。

离线 + 开源

识别在手机本地完成，不联网；代码公开可自审。

Rule

取件码怎么被分成三类

分类依据是短信正文特征，而不是解析出来的地址。

类别判据样例
快递站（人工货架） 短信正文含「海事大学」且取件码含字母 D8-6、S3-2-2628（顺丰）、Y5-7-1（大物）
快递柜（自助取件） 短信正文含「海事大学」且取件码为纯数字 54018314、69824579
校外 短信正文不含「海事大学」 —

Install

安装与升级

Android 10（API 29）及以上。装完不用登录，也不需要注册。

下载安装包

点「下载 APK」保存 parcel-spu-v0.2.1.apk（22.7 MB），手机浏览器下载完下拉通知栏点安装。

允许安装未知来源应用

提示「禁止安装未知应用」时选允许来自此来源，装完可以关掉这个权限。

授予短信权限

首次打开会申请读取短信。小米手机需额外开：权限管理 → 其他权限 → 通知类短信 → 始终允许。

把取件码放上桌面

在系统「小组件 / 插件」里找到「海大取件码」添加即可；条码、取件路线等在右上角菜单里。

FAQ

常见问题

安装时提示「应用未安装」或签名冲突？

手机上还有用旧签名打包的版本（v1.0.57-haida.1 及更早）。先卸载旧版再装最新版即可。

有些短信解析不出来？

解析依赖短信正文特征，少数「服务信息」短信识别不了。可以开启监听第三方 App 通知，或用「新增自定义取件短信 / 新增规则」手动补一条。

取件路线排不出来？

路线需要取件码里有货格号（D8-6 / S3-2-2628 / J5-21）。若仍排不出来，确认菜单里「按取件路线排序」是开着的。

收费吗？会上传我的数据吗？

免费、无广告、不上传。识别完全在本地完成。上游是 shareven/parcel（MIT），海大版改动公开在 本仓库。仅 Android，无 iOS 版。
