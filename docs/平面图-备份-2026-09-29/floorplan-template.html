模型自检 —

    以上通道是程序从你 Excel 的填充色里自己认出来的，不是手写的。

    建议顺序 —

      这份模型的口径

      • 可走格 = 你 Excel 里填了通道色的全部单元格（3362 格），逐格对齐，未改动一列一行
      • 纵向干线 3 条：西侧（靠闸机，列 F~J）、主通道（列 AI~AN）、东侧（列 CK~CP）
      • 横向走廊 10 条（含最北 J/S 区那条）；闸机带 C12:E16 / C17:E21 / C22:E57 可通行，只用于出行
      • 起点＝入口闸机（W59:AB59）；终点＝按件分工：普通件走「7 号普通闸机」C22:E57，S 顺丰件走「顺丰专用闸机 C17:E21 / 顺丰自取出口 C12:E16」—— 依据你 Excel 的闸机标签，此分工待你确认
      • 距离单位＝瓷砖（1 单元格 = 0.5 瓷砖）；同货架内不同格暂视为同一点
      • J / S 有多条货架（J1~J6、S1~S3）；Y 区在你精确版里是一整块，只能定位到东侧通道最近点
      • ≤13 件＝精确最优（Held–Karp）；更多件退化为最近邻 + 2-opt，并如实标「非精确」
