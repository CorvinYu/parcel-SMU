模型自检 —

    以上通道是程序从你 Excel 的填充色里自己认出来的，不是手写的。

    建议顺序 —

      这份模型的口径

      • 可走格 = 你 Excel 里填了通道色的全部单元格（3362 格），逐格对齐，未改动一列一行
      • 纵向干线 3 条：西侧（靠闸机，列 F~J）、主通道（列 AI~AN）、东侧（列 CK~CP）
      • 横向走廊 10 条（含最北 J/S 区那条）；闸机带 C12:E16 / C17:E21 / C22:E57 可通行，只用于出行
      • 起点＝入口闸机（W59:AB59）
      • 🔴 顺丰规则：只要取了 S 件，就必须先到「顺丰专用闸机」出库； 若同时还有普通件，出库后再去普通货架，最后从 7 号普通闸机出库（它也是出站口）直接走人； 只有顺丰件时：顺丰出库机不能出站，还要走到「顺丰自取快递出口」出站才结束。 程序作为「出库点必须在所有 S 件之后 + 路线永远终于出站口」的先后约束，交给 Held–Karp 求最优顺序
      • S 区按格位定位：s1 货位 1~10、s2/s3 各 1~8，左端为 1 向右递增（实测锚点 O7:U7 / O9:U9 / O10:U10）
      • J 柜列按格位定位：沿列由外端（靠通道）向里递增，柜列纵深计入走位； 每列实际格数未实测 ⇒ 按 21 格等比铺开（待确认 Q1b/Q5）
      • Y 大件区在你精确版里是一整块（Y区域）⇒ 只定位到东侧通道最近点，无法分 y1~y8
      • 距离单位＝瓷砖（1 单元格 = 0.5 瓷砖）；普通排货架内不同格暂视为同一点
      • ≤16 件＝精确最优（Held–Karp；状态 2^n×n×2，n=16 约 2.2M）；更多件退化为 「S 块 → 出库 → 普通块」＋（最近邻 / 走廊扫描）两种子各跑 2-opt 取优，并如实标「非精确」 —— 53 件这种量级不可能精确求解（2^53）
