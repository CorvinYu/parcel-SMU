海大快递站 · 俯视图与取件路线模拟

这是**我的模型理解**的站点：一格 = 一块瓷砖。请对照现场看哪些地方画错了；改参数或点图撒点后， 右侧会按同一套算法重算「南门进 → 逐件取 → 西门出」的最优顺序。
点图上的货架格可直接放/收一个取件点（按最近的货架吸附）。

取件码（逗号/空格分隔）

支持：主货架 D8-6；J 柜列 J5-21；顺丰 S3-2-2628；大件 Y5-7-1 / Y8-1-3。

建议顺序 —

    模型参数（改完点「按参数重画」）

    默认值全部来自你的实测：货架宽 3、横向通道 2、背靠背 1（⇒ 相邻通道 3）、纵向通道 3。

    我的模型假设（哪条与现实不符请告诉我）

    • 16 排：A B C D E F G H K L M N O P Q R（无 I、无 J），A 最靠南门。
    • 每两排背靠背（a｜b、c｜d…），**共用一条横向通道**；排间距 = 通道 2 + 背靠背 1 = 3 格。
    • 主纵向通道在**货架 4 与 5 之间**；货架 1~4 在西侧、5~12 在东侧。
    • **背靠背两排之间过不去**（现场确认）：同排东西两侧换边必须回主通道。
    • 同一侧沿通道走 = 横向差；跨到另一侧 = 两边横向相加。
    • 格子：**同一货架内的不同格号暂时当作同一个点**（货架内部几何还没量）。
    • J 柜列 / S 顺丰 / Y 大件按踩点图摆放（J 六列、S 三架、Y y1~y8）。
